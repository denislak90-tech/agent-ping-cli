# Contributor Covenant Code of Conduct (summary)

Be respectful, welcoming, and constructive. Harassment, discrimination, and personal attacks are not tolerated.

Enforcement: violations may lead to warnings, temporary bans, or permanent removal at maintainer discretion. Report issues privately via the maintainer contact on the GitHub profile or a private security advisory — never by public shaming.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
